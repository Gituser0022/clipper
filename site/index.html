    How it works

    From a link to finished clips.

    Clipper has two ways in. Give it a finished video and it finds the big moments for you. Point it at a live stream and it keeps the last few minutes ready to save.

    1. 01
      Paste

      Paste a video link

      A YouTube video or a past broadcast. Twitch videos are expected to work too. Clipper doesn’t download the whole thing to look at it.

    2. 02
      Listen

      Clipper listens for the loud parts

      It streams just the audio and measures how loud each second is. Then it compares every second with the two minutes around it. A crowd cheering, a big laugh or a shout stands out as a spike.

    Runs locally and stays private

    Clipper runs on your computer. Videos go from the site straight to your disk, and nothing is uploaded anywhere.

    Auto-clip loud moments and chat spikes

    During a live stream, Clipper can save a clip by itself when the audio gets much louder than usual or when YouTube or Twitch chat suddenly gets busy. Each clip keeps 60 seconds either side.

    Near-instant live saves

    Live clips are joined from pieces already on disk with no re-encoding, so there’s no waiting and no loss of quality.

    Install

    Set it up once.

    These steps are for a Mac with Homebrew. Each command goes in Terminal.

    1. Install the tools Clipper uses

      brew install python ffmpeg node git

    2. Get the code

      git clone https://github.com/Gituser0022/clipper.git

      You need access to the repository on GitHub to clone it.

    3. Install Clipper

      cd clipper && python3 -m venv .venv && source .venv/bin/activate && pip install -e .

    4. Build the Mac app

      bash scripts/make-mac-app.sh

      This puts Clipper.app in ~/Applications. Double-click it to open Clipper in your browser.

      Or skip the app and start it from Terminal, then open http://localhost:8000:

      clipper serve
    If macOS blocks the app

    Right-click, then Open

    The first time you open Clipper.app, macOS may refuse because the app isn’t from the App Store. Right-click it and choose Open. On macOS 15 or later, go to System Settings, then Privacy & Security, and click Open Anyway.

    On Linux or Windows

    • Python3.10 or newer
    • ffmpegon your PATH
    • Nodeor Deno, for YouTube

    Install with pip install -e ., run clipper serve and open http://localhost:8000. The Mac app is macOS only.

    FAQ

    Questions people ask.

    Does it upload my videos?

    No. Clipper runs on your own computer. It downloads with yt-dlp, cuts with ffmpeg, and saves clips to a folder on your disk. Nothing goes to a Clipper server, because there isn’t one.

    Why does it need Node?

    YouTube needs a JavaScript runtime for yt-dlp to read its videos. Node works, and so does Deno. Clipper doesn’t use it for anything else.

    Which sites work?

    YouTube is tested. Twitch is expected to work. Kick may be blocked by Cloudflare, X works for some live broadcasts, and Instagram Live isn’t supported. See Supported sites for the details.

    Is it free?

    Yes. Clipper is a free tool you run on your own computer. There’s no account and no subscription.

    How does it decide what a “best moment” is?

    It looks for seconds that are much louder than the two minutes around them, like a crowd cheering or a big reaction. It ranks those by how far they stand out and keeps the biggest ones that don’t overlap. Quiet highlights won’t be found this way, so you can always set your own start and end.

    YouTube stopped working. What now?

    Update yt-dlp first, inside Clipper’s environment: pip install -U "yt-dlp[default]". Sites change often and yt-dlp keeps up with them.
