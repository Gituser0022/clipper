How it works

A rolling recording means you never miss the moment.

You can’t clip something that already happened unless it was recorded. Clipper records the stream the whole time you’re watching and keeps only the last few minutes, so clips cost no extra waiting.

Step 1

Read the stream

yt-dlp finds the stream behind the URL and handles each site’s quirks. You paste a link and nothing else.

Step 2

Keep 2-second segments

ffmpeg cuts the stream into small MPEG-TS files. Anything older than your rewind window (5 minutes by default) is deleted.

deleted · buffered · clipped
Step 3

Stitch, don’t re-encode

A clip is the newest segments joined into one MP4 with the video copied as-is. It saves in about a second and keeps full quality.

Features

Built for people who clip streams for a living.

Rewind live streams

Save the last 15, 30 or 60 seconds, or any length up to your buffer.

Catch what happens next

“30s + next 15s” keeps recording, then saves the whole moment with its payoff.

One-key clipping

Press C in the web app or Enter in the terminal. No menus while the stream is going.

Cut finished videos

Give a start and end time. Only that section downloads, not the whole video.

Frame-accurate mode

Optional precise cuts re-encode the edges, so the clip starts on the exact frame.

Web app or terminal

The same engine runs behind the browser UI and the clipper command.

Command line

Install

Running in three commands.

You need Python 3.10 or newer, ffmpeg, and Node.js or Deno (YouTube needs a JavaScript runtime).

1 · Get the codecd clipper
2 · Installpip install -e .
